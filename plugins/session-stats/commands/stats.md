---
description: 显示当前会话的 token 用量与性能统计
---

运行下面的命令获取当前会话的统计 JSON（不要做其他任何操作）：

```bash
node "$HOME/.zcode/session-stats/bin/cli.mjs" --json
```

拿到 JSON 后，用中文渲染一张紧凑的统计卡片，直接给出结果，不要额外解释：

1. 首行一行式摘要（用 `｜` 分隔）：`N 轮 · M 步 ｜ LLM 耗时 ｜ 首 token 平均 X s · N tok/s ｜ 缓存命中 P% ｜ 输入 X tok · 输出 Y tok`（token 数用 K/M 缩写，保留一位小数）。
2. 第二行小字：工具调用次数（含失败数）、模型请求次数（含重试数）、当前模型、上下文占用（最近一次请求输入 token）。
3. 若 `live` 非空，在最前面注明「⟳ 当前有一轮正在进行中」。
4. 最后附「最近轮次」小表格，列：轮次、状态（进行中/完成）、LLM 耗时、首 token、步数、输入、输出。JSON 里 `turns` 数组第一条是最近的轮。
5. 数字一律使用返回的原始值换算，不要编造。
